# 考研错题本

这是一个可部署的静态网页，用来按目录收录考研错题的题目截图与解析截图。当前版本使用 Supabase 提供邮箱密码登录、云端数据库和截图存储；每个账号只能读取和修改自己的错题。

## 云端配置

1. 打开 Supabase 项目的 SQL Editor。
2. 执行 `supabase-schema.sql`，创建 `questions`、`user_settings`、`question-images` bucket 和 RLS 策略。
3. 检查 `supabase-config.js` 里的项目地址和 publishable/anon key。
4. 如果希望用户注册后立刻登录，在 Supabase Dashboard 的 Authentication 设置里关闭邮箱确认；如果开启邮箱确认，用户注册后需要先点邮件里的确认链接再登录。

## 使用方式

1. 打开 `index.html` 查看页面，或部署到 Vercel / Netlify / GitHub Pages。
2. 使用邮箱和密码登录；新用户可以点击“注册新账号”。
2. 页面固定四个大类：`数学`、`英语`、`政治`、`408`。
3. 点击“新增学科 / 题型”，新建学科时先选择它属于哪个大类，例如把 `高等数学` 放在 `数学` 下。
4. 新建题型 / 目录时，必须先选择大类和学科，例如把 `一元函数微分学` 放在 `数学 / 高等数学` 下。
5. 在左侧选择具体目录，例如 `数学 / 高等数学 / 一元函数微分学`。
6. 点击主页面右上角的 `+`。
7. 电脑端在弹窗中分别点击“题目截图”和“解析截图”区域后粘贴图片；手机端点击预览区右侧的 `+`，选择拍照或从相册选择。
8. 点击“保存错题”。

没有点击 `+` 时，页面只显示当前目录下已有的题目和解析。答案与解析默认折叠在每道题之后。

新增错题会追加到当前目录已有题目后面；题目列表每页显示 5 道，可以在页面底部翻页。

如果左侧选择了某个学科，但题型选择“全部目录”，页面会显示该学科下所有目录里的错题，并用分割线区分不同题型。

每道题右上角有大头针按钮。点击后，会在当前浏览层级的最前面生成一份置顶副本；原题仍保留在原位置。多个置顶题中，后置顶的显示在更前面。点击置顶副本上的大头针可以取消置顶。

在“新增学科 / 题型”的管理弹窗中，可以重命名科目大类、学科和题型目录。重命名会同步更新其下的错题、置顶位置和目录记录。

每道题右上角的“迁移”按钮可以把当前题目移动到其他科目大类、学科和题型目录下。目标学科或目录不存在时，页面会询问是否新建后迁移。

## 存储方式

页面中新增的学科、题型和展示设置会保存到 Supabase 的 `user_settings` 表，并按登录账号隔离。粘贴或上传进去的截图会上传到 Supabase Storage 的 `question-images` 私有 bucket；错题记录保存在 `questions` 表。浏览器本地只保留一份当前账号的设置缓存。

## 备份与恢复

左侧头像上方有“导出题库 JSON”、“覆盖导入 JSON”和“合并导入 JSON”按钮。

导出会生成一个包含目录结构、重命名后的科目大类、题目截图、解析截图、备注和置顶信息的 JSON 文件，文件名会带有导出时间和题目数量，例如 `错题本备份-2026-06-26-1530-共128题.json`。建议手动保存到专属备份文件夹，按时间自行保留或删除旧文件。

覆盖导入会询问是否先导出现有题库备份，然后清空当前账号的云端题库数据，再完全恢复 JSON 里的题库内容。账号密码不会被导出，也不会被导入覆盖。旧版 JSON 里的 base64 截图会自动上传到 Supabase Storage。

合并导入用于两个人交换题库。每道题都会保留创建者标识；合并时只导入该 JSON 导出者自己创建、且当前题库中不存在的题。目标目录不存在时会自动创建同名大类、学科和目录。

页面上方的“显示ID”按钮可以显示每道题的创建者登录 ID；底层去重使用稳定的创建者标识，不直接依赖显示名称。

如果要给别人查看题库，可以把整个项目文件夹作为网页空壳发给对方，再把导出的 JSON 文件一并发给对方；对方打开 `index.html` 后导入 JSON 即可看到题库。

## 代码结构

- `index.html`：页面结构和弹窗模板。
- `styles.css`：整体布局、卡片、弹窗和移动端样式。
- `questions.js`：默认大类、初始学科和内置错题数据。
- `supabase-config.js`：Supabase 项目地址和 publishable/anon key。
- `supabase-schema.sql`：Supabase 数据表、RLS 策略和 Storage bucket 初始化脚本。
- `storage.js`：Supabase Auth、Database、Storage 和用户设置缓存相关逻辑。
- `ui-utils.js`：目录 key、去重、图片渲染和弹窗开关等通用工具。
- `app.js`：应用状态、目录管理、题目渲染、粘贴新增、分页、置顶和事件绑定。

## 删除

删除学科、题型或错题时，页面会先弹出确认。

删除题型不会删除错题，已有错题会改为“未分类”。删除学科不会删除错题，已有错题会改为“未分类学科”。

## 初始目录

固定大类可以在 `questions.js` 的 `window.DEFAULT_CATEGORIES` 中查看；初始学科可以在 `window.DEFAULT_SUBJECT_FOLDERS` 中维护。
